# Token Efficiency & Response Guidelines

## 1. Response Style
- **Concise & Direct**: Provide solutions and answers directly without preamble, polite filler, or unsolicited summary conclusions.
- **Code Snippets Only**: When modifying or providing code, output ONLY the relevant function, class, or `diff`. Never regurgitate entire files unless explicitly requested.
- **No Unsolicited Explanations**: Do not explain standard code or concepts unless the user specifically asks "why" or "explain".

## 2. Context & File Handling
- Never read or analyze binary files, media files, `.sqlite3`, `.exe`, or large static vendor bundles unless strictly required.
- Keep tool calls minimal and focused.
